# Security policy

## Supported versions

Security fixes are made in the latest release. Please update to it before reporting.

## Reporting a vulnerability

Please do **not** open a public issue for a security problem. Report it privately by e-mail to
**madygrapher@gmail.com**, with:

- the MadY version (**Help ▸ About MadY**) and your operating system;
- what the problem is and what an attacker could do with it;
- the steps or a file that shows it.

You will get a reply, and a fix will be released as soon as it is ready. Please keep the problem
private until then.

## What MadY does with your data

MadY runs entirely on your computer. The installed program makes no network requests: projects,
data and results stay on your disk. A bug report is sent only when you send the e-mail it
prepares, and it includes your data only if you choose to.
