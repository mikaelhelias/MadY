# Sources and licences of the example scripts

The R scripts in this folder are test inputs for the ggplot2 script importer
(`packages/core/src/ggplotImport.test.ts`, `apps/desktop/src/renderer/src/shell/ggplot-import.test.tsx`).
They are not part of the program and are not shipped in the installer. Each script names its
source in its first line.

| Scripts | Source | Licence |
|---|---|---|
| `01`–`44` | Examples from the ggplot2 reference documentation, <https://ggplot2.tidyverse.org/reference/> | MIT, below |
| `45`–`52` | Examples from the R Graph Gallery, <https://r-graph-gallery.com/> (<https://github.com/holtzy/R-graph-gallery>) | MIT, below |
| `53`–`58` | Written for these tests (53 and 54 draw R's built-in `ToothGrowth` data) | GPL-3.0-or-later, as the rest of MadY |
